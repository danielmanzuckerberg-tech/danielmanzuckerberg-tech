# Анимация с чувством меры.

> Бортовой журнал Moritz · UI / UX · 4 минуты

Хорошее движение объясняет, что изменилось. Плохое заставляет ждать, отвлекает от чтения и иногда вызывает физический дискомфорт. В интерфейсе важен не сам эффект, а причина его появления.

## Дайте движению работу

Панель может плавно показать связь с кнопкой, которая её открыла. Карточка — немного приподняться, подтверждая, что это ссылка. Переход между состояниями — сохранить ощущение непрерывности.

Если анимация ничего не объясняет, сначала попробуйте убрать её. Интерфейс часто становится лучше без дополнительного эффекта.

## Содержание доступно с первого кадра

Не делайте текст невидимым до запуска JavaScript. Ошибка загрузки, медленное устройство или отключённый скрипт не должны превращать страницу в пустой экран.

Короткое появление может начинаться с уже читаемого содержимого. Фиксируйте размеры медиа заранее, чтобы движение не сопровождалось прыжками соседних блоков.

## Уважайте уменьшение движения

```css
@media (prefers-reduced-motion: reduce) {
  .entrance {
    animation: none;
    transform: none;
    opacity: 1;
  }

  html {
    scroll-behavior: auto;
  }
}
```

Это не запрет на всю обратную связь. Фокус, цвет и мгновенная смена состояния по-прежнему помогают ориентироваться. Но большие перемещения, параллакс и автоматическое вращение лучше отключить.

## 3D начинается с согласия

Трёхмерная сцена требует графических ресурсов. Если она дополняет содержимое, загружайте её отдельно, а не заставляйте каждый визит скачивать движок. Предлагайте понятный запуск, статическое описание и возможность остановить автоматическое вращение.

В Compass Lab модель можно вращать мышью или касанием, а курс и ракурс — менять обычными кнопками. Если WebGL недоступен, остаётся описание и скачивание STL. Смысл эксперимента не зависит от конкретного устройства.

## Проверяйте не только мышью

- У каждой кнопки и ссылки должно быть понятное имя.
- Фокус клавиатуры должен оставаться видимым.
- Элементы не должны двигаться из-под указателя перед нажатием.
- Всплывающая информация не должна быть доступна только при наведении.
- Автоматическое движение должно иметь управление, если оно продолжается.

Мягкая тень и небольшое смещение не заменяют эти правила. Профессиональная анимация остаётся удобной, когда эффект отключён.
