# Moritz Compass / 3D Lab

> Рабочий интерактивный эксперимент · Three.js · React Three Fiber · STL

Небольшой навигационный компас в палитре бортового журнала: латунный корпус, тёмно-синий циферблат и светлая стрелка с голубой осью. Геометрия создаётся программно — это настоящая объёмная модель, а не картинка, которая поворачивается вместе с карточкой.

## Что можно делать

В веб-версии доступны вращение мышью и касанием, масштабирование, изменение курса стрелки, выбор ракурса и разнесение деталей по слоям. Автовращение запускается отдельно и выключено по умолчанию.

Для клавиатуры предусмотрены обычные кнопки ракурса, ползунок курса и сброс. Сцена загружается по запросу. Если WebGL недоступен, описание и скачивание модели остаются доступны.

## Четыре части

- **Корпус:** нижняя чашка и крепёжное кольцо.
- **Циферблат:** основа, шкала и маркеры направлений.
- **Стрелка:** две объёмные половины и центральная ось.
- **Обод:** верхнее защитное кольцо.

Разнесённый вид нужен для понимания устройства, а не только для визуального эффекта. Модель не связана с датчиками устройства и не измеряет магнитный север.

## Открыть на GitHub

[Открыть и вращать STL-модель](../models/moritz-compass.stl)

GitHub поддерживает отдельный просмотрщик STL: мышью можно вращать модель, колесом — менять масштаб. В самом README произвольный WebGL не исполняется.

STL сохраняет геометрию, но не материалы и не управляющие элементы веб-сцены. Это демонстрационная цифровая модель, не подготовленная к 3D-печати: детали не гарантированно соединены в водонепроницаемое тело, размеры не нормированы под производство.
