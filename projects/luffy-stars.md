# Luffy Stars

> Архитектурный концепт · Developer Tools · Публичного работающего сервиса пока нет

## Задача

Наблюдать за публичными репозиториями: звёздами, релизами, изменениями и доступной активностью. Показывать источник и время получения вместо выдуманной «живой» статистики.

## Устройство

Плановый сборщик сохраняет снимки разрешённых публичных данных. Он учитывает пагинацию, лимиты GitHub API, кэширование и условные запросы. Отсутствие нового снимка обозначается как устаревание, а не нулевое значение.

График показывает только реально собранные точки. Если история ещё не накоплена, система не дорисовывает прошлое на основе текущего числа звёзд.

## Критерии готовности

- [ ] Наблюдение за репозиториями с проверяемыми ссылками
- [ ] Хранение датированных снимков
- [ ] Явная обработка приватизации, удаления и переименования
- [ ] Различение пропуска данных и нулевого результата
- [ ] Экспорт исходных измерений
- [ ] Алерт на неработающий сборщик, а не только на падение метрики

## Что уже есть в этом профиле

В Logbook используется упрощённая часть этой идеи: настоящий датированный снимок календаря GitHub, график и таблица. Это не означает, что отдельный сервис Luffy Stars уже запущен.
